Подарки Пермь

Политика конфиденциальности

Действует с 27 октября 2026 года

Этот документ описывает, как приложение «Секретарь Том» (далее — «приложение») обращается с данными. Приложение — личный помощник владелицы магазина «Подарки Пермь» Ольги. Оно работает через Telegram-бота и сервер, которыми управляет сама владелица.

Кто пользуется приложением

Приложение предназначено только для личного использования владелицей. Оно не предлагается другим людям, и посторонние пользователи не могут подключить к нему свои аккаунты.

Какие данные приложение получает

С разрешения владелицы приложение получает доступ к её собственному аккаунту Google и использует следующие сервисы:

  • Gmail — чтение, составление и отправка писем по просьбе владелицы;
  • Google Диск — поиск, чтение и сохранение файлов;
  • Google Таблицы и Google Документы — чтение и редактирование таблиц и документов;
  • Google Календарь — просмотр и создание событий.

Кроме того, приложение обрабатывает сообщения, которые владелица отправляет Telegram-боту, включая голосовые.

Как используются данные

Данные используются только для того, чтобы выполнять поручения владелицы: находить информацию, готовить ответы, работать с письмами, файлами, таблицами, документами и календарём. Данные не используются для рекламы, не продаются и не передаются третьим лицам, кроме сервисов, которые нужны для работы самого приложения (например, сервиса распознавания речи или языковой модели), и только в объёме, необходимом для выполнения поручения.

Использование и передача информации, полученной через API Google, соответствуют Правилам Google в отношении пользовательских данных API-сервисов, включая требования об ограниченном использовании (Limited Use).

Хранение и защита

Ключи доступа к аккаунту Google хранятся на защищённом сервере владелицы. Данные хранятся только столько, сколько нужно для выполнения поручения.

Как отозвать доступ

Доступ приложения к аккаунту Google можно отозвать в любой момент на странице myaccount.google.com/permissions. После этого приложение больше не сможет получать данные из аккаунта.
